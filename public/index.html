📈 Performance Intelligence
Building performance intelligence…
Build 20 analyses only verified settled prediction snapshots. ROI is shown only when genuine historical odds exist; no odds or results are invented.
📊 Performance by market
Market metrics are calculated from the canonical pre-kickoff snapshot for each fixture. Unsupported settlement markets are excluded rather than guessed.
🎯 Probability calibration
Each row groups predictions by their stated probability range. Predicted probability is compared with the observed result rate for the same group.
🧠 Oracle Confidence & Calibration Engine
Measuring confidence calibration…
Build 23 does not simply inflate confidence. It compares historical predicted probabilities with verified outcomes, applies small-sample safeguards and makes only bounded adjustments. When evidence is weak, the original model probability remains dominant.
🧪 Backtesting methodology
🧪 Genuine Backtesting Lab
🧠 Persistent Team Strength
Ratings update only after verified final results. Each prediction snapshot stores the pre-match team ratings used by the engine, preventing future results from leaking into past predictions.
🎯 Specialist Market + League Models
Specialist calibration is learned only from canonical settled predictions. League adjustments require meaningful samples and are tightly bounded to reduce overfitting.
🧠 Automatic Prediction Reassessment
Loading prediction reassessments…
Verified pre-kickoff changes are assessed separately from the original prediction. The original snapshot is never rewritten.
📡 Live Intelligence Monitor
Checking monitored fixtures…
When enabled by the site administrator, a quota-limited scheduled worker checks eligible fixtures. Monitoring may be paused to protect API Football quotas. Original prediction snapshots remain immutable.
🧬 Build 30 — Self-Learning Model Optimisation
Checking optimisation evidence…
Build 30 learns component weights from chronological training data, protects the holdout from leakage, and only activates bounded improvements after sufficient evidence. New weights only activate after enough verified results and a measurable holdout improvement; otherwise the current model is retained.
🧠 Oracle Learning Persistence
Checking learning storage…
Learning backups are restricted to administrators. Export using a secure server request with your admin token; no credentials are placed in the browser.
Prediction learning remains usable when Netlify Blobs is unavailable. Durable server-side learning requires Netlify Blobs credentials; otherwise Soccer Oracle safely uses a runtime fallback and provides an export path.
